Workout Recommender System
An interactive machine learning-powered web application built with Streamlit that provides personalized exercise and workout recommendations based on individual user profiles, difficulty levels, target muscle groups, and available equipment.

Key Features
Personalized Recommendations: Filters and recommends exercises tailored to user experience, target body parts, and available equipment.

ML-Driven Difficulty Classification: Leverages pre-trained machine learning models (difficulty_model.pkl) and encoders (difficulty_encoder.pkl) to dynamically categorize and match workout intensity.

Interactive Web Interface: Streamlit UI for seamless parameter selection and routine generation.

Custom Configuration: Custom .streamlit theme configurations for an optimized user experience.
